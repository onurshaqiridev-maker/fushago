# FushaGo — Tech stack

| Part | Technology | Why (one sentence) |
|---|---|---|
| **Front end** | **React + Vite** (JavaScript) | React is the most-used way to build web pages, so there is lots of help online, and Vite starts the project in seconds and shows changes instantly. |
| **Back end** | **Node.js + Express** (JavaScript) | Express is the simplest well-known web server for Node.js, and using JavaScript on both sides means learning only one language. |
| **Database** | **SQLite** via **Prisma** | SQLite is just one file in the project (no server to install), and Prisma lets us write the data models in one easy-to-read file and creates the tables for us with migrations. |

Versions used: Node.js 22, React 19, Vite 6, Express 4, Prisma 6.
