# FushaGo — notes for Claude Code

Before building any feature, read:
- `docs/rules-and-flows.md`: roles, flows and business rules. Follow them exactly; if a rule is unclear, ask instead of guessing.
- `docs/brand-book.md`: use only the brand colours and fonts listed there (Poppins + Inter; #12A150, #0B1F17, #C8F31D, #F4F7F2).
- `docs/business.md`: who the product is for and why.

Respect the "What version 1 will NOT do" list. Do not add online payments, SMS, or a native app in v1.

The owner of this project is a beginner: keep code simple, explain changes in plain words.
